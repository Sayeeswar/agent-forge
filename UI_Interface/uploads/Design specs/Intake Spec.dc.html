the skip path
Skipping opens the session immediately with the subtopic held empty. The AI infers it from the first exchange and confirms inline, once: “I’m reading this as Gaussian curvature of a sphere — say so if that’s not it.” Confirmed, it is written back into the intake record like any tapped answer.
saves
topic · subtopic (nullable) · inferredBy
The subtopic is the one step where not knowing the answer is the normal case, so it is the only one with an explicit way out. Everything above it is a fact the student holds; this is the first question that asks them to diagnose themselves.

Editing an Answer

Every answered step stays tappable. Changing one keeps whatever below it is still valid — so correcting a typo in the university name doesn’t cost the student their topic.

The test for “still valid” is membership: an answer survives if it exists in the catalogue the new answer opens. Anything cleared is re-asked in place, with the steps below it left alone until it’s answered.

The Second Session

The stepper runs in full, pre-filled from last time. The student confirms by tapping down the list — which is faster than reading a summary and deciding whether to trust it.

pre-filled
Steps 1 – 5 and step 8 arrive filled and ticked. Tapping a tick confirms; tapping the answer reopens it.
never pre-filled
Topic and subtopic. A new session means new work, and inheriting last week’s topic is how a student ends up in the wrong one.
no shortcut
Eight steps, every session, however recently the last one ran. Confirming is the point: it is the moment a student notices they’ve moved on from what the record says.
